# AI_collection

## 本機使用與資料位置

在專案資料夾執行 `python server.py`（或 PowerShell 執行 `./start.ps1`），
再開啟 <http://127.0.0.1:8765>。需要 Python 3，不需安裝套件。
使用期間請保持啟動程式執行。

- `data/library.json`：完整資料庫，包含兩個分頁的文件全文、附件內容、版本、收藏、關聯及回收桶。第一次開啟本機網站時建立。
- `data/library.previous.json`：每次儲存前的上一份完整資料。
- 附件以文字或 Base64 包含在 JSON 中，可從網站下載原始格式。
- 寫入採暫存檔後原子替換；不同分頁同時修改時會提示衝突，避免靜默覆蓋。
- 本機模式使用檔案作為主要儲存，不自動連接 Firebase。服務僅監聽本機，不提供 data 檔案的靜態下載。

## 搬移舊資料

若舊資料位於相同的 `http://127.0.0.1:8765` 瀏覽器來源，且尚無
`data/library.json`，首次載入會自動將原 IndexedDB 資料複製到檔案，並保留原資料庫。

若舊資料位於遠端網址、其他連接埠、其他瀏覽器或直接開啟的 HTML：

1. 在原瀏覽器開啟原網站；若資料在雲端，先登入並等同步完成。
2. 若原網站已有新版按鈕，按「匯出資料庫」→「完整搬移備份（兩分頁＋收藏）」可一併備份兩個分頁、收藏與回收桶。若仍是舊版，每個主分頁各按「匯出資料庫」→「全部已匯入資料」→「下載 JSON 備份」（舊版分頁備份不包含收藏）。也可使用既有的完整私人雲端備份。
3. 開啟本機網站，切換到對應主分頁，按「匯入」選取 JSON，再「合併匯入」。完整私人雲端備份可同時還原兩個分頁。
4. 確認文件、附件與版本，重新整理後再確認資料仍在。原網站的匯出備份請保留。

直接雙擊 `index.html` 或使用遠端靜態網站仍是舊的瀏覽器／雲端模式；
要寫入本專案的 data，請使用上述本機啟動方式。

驗證：`python -m unittest discover -s tests` 與 `node --test tests/storage.test.cjs`。
