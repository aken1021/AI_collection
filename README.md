# AI_collection

## 資料位置

所有技能、規則、知識、附件、關聯、收藏、版本與回收桶均保存於
`data/library.json`。網頁讀取這個檔案，不再使用瀏覽器資料庫或 Firebase
作為內容來源。匯入後會複製完整內容與附件進 JSON，不只存路徑或連結。

閱讀文件時，JSON、程式碼與其他 UTF-8 文字檔直接顯示全文；文件附帶的
文字附件可展開「閱讀附件」。舊資料若已保存原始檔案，也能直接閱讀，無需重新匯入。
非文字附件仍完整保存，可下載原始檔案。換電腦時，請一併同步更新後的
`data/library.json` 及程式檔案；透過 GitHub 搬移需 commit、push，再於另一台 pull。

## 直接開啟 index.html

1. 使用 Chrome 或 Edge 開啟 `index.html`。
2. 按上方「連接 data 資料夾」，選取此專案的 `data` 資料夾並允許讀寫。
   也可以選取包含 `data` 的專案根目錄。
3. 網頁會從選取資料夾的 `library.json` 載入資料。之後每次匯入、編輯、
   刪除、還原都直接寫回同一檔案，並保留 `library.previous.json`。
4. 瀏覽器會嘗試記住資料夾授權；若重新開啟後要求連接，再按一次即可。

瀏覽器不允許一般 HTML 未經授權讀寫任意本機檔案，所以直接雙擊 HTML 時
需要上述資料夾授權。IndexedDB 只記住資料夾控制代碼，不保存資料內容。
無法使用資料夾選取功能的瀏覽器，可採用下面的本機服務方式。

## 本機服務（免選資料夾）

在專案資料夾執行 `python server.py`，或在 PowerShell 執行 `./start.ps1`，
再開啟 <http://127.0.0.1:8765>。需要 Python 3，不需安裝套件。
服務執行期間自動讀寫專案的 `data/library.json`，不必另外授權資料夾。
服務只監聽本機；JSON 寫入採暫存檔後原子替換，並保留上一份備份。
不同分頁或程式同時修改檔案時會提示衝突，避免靜默覆蓋。

## 遠端靜態網站與 Git

遠端網站開啟時會讀取部署的 `data/library.json`，因此下載或部署本專案後
可以取得同一批資料。靜態網站不能直接改寫 GitHub 檔案；要修改資料，
先連接本機專案的 data 資料夾，完成後將更新的 `data/library.json`
commit 並 push，遠端才會更新。寫入失敗會顯示錯誤，不會偷偷改存瀏覽器。
`library.previous.json` 不納入版本控制。

## 匯入與更新

所有文件、ZIP、資料夾與 JSON 備份統一從「匯入」處理。
匯入時先比對既有資料：技能依名稱、文件依完整相對路徑判斷，
忽略 .claude/skills、skills 等工具外層目錄；不同主分頁、不同技能中的同名文件分開保留。
預覽顯示新增與重複項目。預設勾選「更新重複資料」，更新時保存舊版本；
取消勾選則跳過重複項目並保留既有內容。完整 JSON 備份也套用同樣規則。
全文與附件直接寫入 data/library.json，不再提供讀取舊瀏覽器內容的功能。

「匯出資料庫」中的「完整資料庫備份（兩分頁＋收藏）」可保留兩個分頁、
附件、版本、收藏及回收桶。請定期備份整個 data 資料夾。
